Hk グラフでの CLIQUES アルゴリズム実行

このページでは、Tomita–Tanaka–Takahashi の CLIQUES アルゴリズムを、実際の H2 グラフ（n=26頂点）上で実行し、すべてのステップを追うことができます。

重要なポイント： guard（ガード）は自分のペアとつながっていません。そのため、ピボットになった guard は必ずペアの2頂点を分岐候補として選びます。この2つの子呼び出しはどちらも同じ条件（guided call）を満たし、再帰的に2分岐を繰り返します。

Hk グラフの構造

H2 グラフは以下の3種類の頂点から構成されます：

  • ● guard U: {g1, g2} （2個）
  • ● ペア M: B1={a1, b1}, B2={a2, b2} （4個、クリーク）
  • ● witness W: 各M頂点に5個ずつ （20個、独立集合）

辺がないのは4種類だけ：

  1. guard 同士（U は独立集合）
  2. gi と自分のペア Bi の2頂点
  3. witness と、その witness が属する頂点
  4. witness 同士（W は独立集合）
