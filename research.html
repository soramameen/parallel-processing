研究プロジェクト — 並列極大クリーク列挙

極大クリーク列挙の並列化研究

Bron–Kerbosch法（Tomita/CLIQUESピボット版）とEppstein法の並列化を、学部卒業研究として発表できるレベルで完成させる。定量評価、視覚的な結果提示、考察を含めた体系的アプローチ。

実装言語 Python 3.12 並列化 multiprocessing / 非対称コア対応 評価データ SNAP (ca-AstroPh, ca-HepPh, soc-sign-epinions)

研究ミッション

Bron–Kerbosch（ピボット版 = Tomita/CLIQUES）の並列化を、学部卒業研究として発表できるレベルで完成させる。

現在のフェーズ

Eppstein–Löffler–Strash (2010) の degeneracy ordering を理解し、並列化の分割戦略（root-split）の理論的裏付けを構築中。

アプローチ

アルゴリズムを自分の言葉で説明 → 逐次実装 → 大規模データでベンチ → 並列化 → 定量評価 → グラフで視覚化 → 考察

研究方針

焦らず理解を深める。C/OpenMP実装や複数アルゴリズムの試食はせず、Pythonで1つのアルゴリズムを深く理解し完成させる。

主要アルゴリズム

Baseline / Pivot版

Bron–Kerbosch (Tomita)

ピボット最適化を使った極大クリーク列挙の標準アルゴリズム。候補集合と除外集合を再帰的に更新し、枝刈りによる効率化を実現。

soc-sign-epinions 167.3 秒
ca-AstroPh 2.29 秒
ca-HepPh 1.01 秒
縮退順序版

Eppstein Algorithm

縮退順序（degeneracy ordering）で最外層を回し、疎なグラフで優れた性能を発揮。計算量 O(d·n·3^(d/3)) で、縮退数 d が小さいほど有利。

soc-sign-epinions 94.9 秒 (1.8倍高速)
ca-AstroPh 0.87 秒 (2.6倍高速)
木構造 n=20k 16.6倍高速

主要な知見

  • 負荷の偏在性: soc-sign-epinions では上位1%の頂点が全仕事の94.7%を占め、縮退順序の末尾（密なコア）に集中する
  • バッチサイズの影響: バッチサイズを512→64に細分化することで、8 workerのパフォーマンスが70秒→27.7秒に改善
  • 非対称コアの配分戦略: interleave配分が静的なblock配分より1.04〜1.76倍高速。速度比rを使わない配り方が最速群に入る
  • コア間移動の影響: OS がworkerをコア間で移動させることが、M4実機での性能特性を説明する主要因（仮説H5）
  • 早期終了の最適化: 候補集合がクリークなら直接答える最適化により、ca-HepPhが1.24倍、ca-AstroPhが1.08倍高速化
  • Eppsteinの適用範囲: 疎なグラフ（縮退数dが小さい）で圧倒的に優位。密グラフでは互角、完全グラフでは逆転
